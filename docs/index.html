Overview

From 9% campaign luck to model-guided conversion

AllLife Bank’s liability base is large; its borrower base is not. Last year’s personal-loan campaign converted just over 9%. This project builds a recall-aware classifier so marketing can prioritize customers with the highest probability of accepting a loan — without inventing black-box complexity.

Topics in depth

Skills demonstrated

Filter by theme, then expand any topic for the concrete technique used in this project.

Personal loan acceptance is a minority class (~9%). Distributions, value counts, and stratified splits keep that signal intact so accuracy alone cannot look “good” while missing converters.
Income and CCAvg are right-skewed; Age and Experience correlate ~0.99. Education and product holdings (especially CD accounts in tree rules) interact with spend and family size in the decision paths.
Used DecisionTreeClassifier so marketing can read exportable rules. Compared default trees, class_weight='balanced', hyperparameter pre-pruning, and CCP post-pruning — not a grab-bag of unrelated algorithms.
Pre-pruning searched max_depth, max_leaf_nodes, and min_samples_split. Post-pruning swept ccp_alpha for peak recall. Selected model: depth 6, 50 leaf nodes, min split 30.
False negatives (missed likely borrowers) waste growth opportunity. Model selection optimized test recall while watching precision and F1 so outreach does not explode false positives.
Income, family size, education level, and credit-card spend dominate importance. Rules surface clear segments (e.g. higher income + larger family / graduate+ education) for campaign prioritization.

Model comparison on the holdout set
